# My Website

A personal portfolio website for Demarcus Studmire, built with HTML and CSS.

## Overview

This project showcases:
- a professional introduction and hero section
- an About Me section
- a Skills section
- featured project cards
- contact links and resume download option

## File Structure

- `index.html` — main page content and structure
- `style.css` — site styling and layout
- `DeMarcus_Studmire_Resume_v2.pdf` — downloadable resume
- `README.md` — project documentation

## Preview locally

Open `index.html` directly in a browser, or serve the site locally:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Technologies used

- HTML

- Google Fonts
